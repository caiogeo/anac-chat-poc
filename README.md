# Pergunte à fila (POC ANAC Pistas)

Página estática do chat GIS da prova de conceito da Imagem Geosistemas para a ANAC: assistente de IA da Esri (componente
`arcgis-assistant` do ArcGIS Maps SDK for JavaScript, em beta) sobre o web map da fila de fiscalização.

- Publicada pelo GitHub Pages para ser mostrada dentro do aplicativo da POC (Experience Builder), que só aceita páginas https.
- Não tem chave nem senha: cada pessoa entra com o próprio usuário da organização ArcGIS Online. O web map só abre para quem tem acesso.
- `?embed=1` esconde o cabeçalho (modo usado dentro do aplicativo).
- ICP, prioridade e vistorias da POC são fictícios. Não é sistema oficial da ANAC.
